## Design decisions and shared code

- Figma remains the visual source of truth: Funnel Sans/Funnel Display, existing local brand assets, warm white workspace surfaces, and existing orange-to-coral gradient tokens were reused.
- Updated the unified posting feed to its current two-column card layout with state-specific lifecycle actions. Removed illustrations absent from the retrieved posting/editor/detail references.
- Added company overview and edit states on the existing profile route (`?edit=true`); shared edited-field PATCH behavior prevents unloaded values from being erased.
- Kept the DAG editor and its explicit transitions, branches, joins, zoom, dragging and keyboard controls. Graph persistence remains unavailable because its handlers are missing.
- Responsive choices where Figma has no mobile frame: stack cards and form columns; retain labeled controls and horizontal table/graph scrolling; keep the existing mobile navigation and dialog focus behavior.
- Added stable explicit textarea labels, unsaved-change protection, save/submission guards and readable unavailable statistics. No new UI dependency, font, icon package, or backend change was introduced.
- The PATCH response updates the current profile screen; missing read endpoints prevent complete overview/reload behavior. Unsupported video upload, offers, grading, administration, feedback and other mutations remain distinguishable from supported actions.
