## Design decisions and shared code

- Figma remains the visual source: Funnel Sans/Funnel Display, local brand assets and existing orange-to-coral gradient tokens are reused.
- Updated the DAG palette, toolbar, selected nodes and inspector. Downloaded 16 exact SVG assets; intrinsic dimensions are retained. Dependencies determine node columns without inventing edges. Added bounded undo/redo, fit-to-view and browser leave protection for local graph edits.
- Graph persistence, publication, privacy policy and migration remain unavailable. Unsupported controls are labeled or disabled; loaded ordered-stage editing stays separate from local DAG edits.
- Replaced the creation form at `/employer/offers` with the dedicated overview and URL-backed filters/pagination. `/employer/offers/new` remains the creation destination. The offers backend is planned; the contract lacks candidate display identity.
- Wired candidate profile GET before mounting editable defaults. Existing company/interviewer reads are retained; profile writes patch edited fields. Module edits preserve behavioral and minimum-test settings from the current backend.
- Added reviewed threshold changes through the registered POST preview / PUT apply operations, including exact preview echo, stale request cancellation, conflict refresh and duplicate-submit prevention. Interview outcome POST is connected when an authorized record is available; discovery is still missing.
- Removed header illustrations from screens whose retrieved references omit them. Shared primary actions use Figma green with dark text; orange-to-coral remains in the gradient slots.
- With no mobile frames, palettes/cards/forms stack and tables/graphs retain local scrolling. Toolbar targets stay at least 44px; graph keyboard movement, shared visible focus, reduced-motion behavior and dialog focus are retained.
- No new dependency, font, icon package, route, backend source change or database write was introduced.
